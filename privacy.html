Privacy Policy

Midnight Whispers Analytics · Last updated November 5, 2026

Midnight Whispers Analytics is a personal, single-user integration built by the operator of the Midnight Whispers content channel. It exists solely to let that one person view their own TikTok account's performance data through TikTok's official API, inside their own development tools. It is not offered as a public service, and no one other than the account owner can use it.

What this connects to

When the account owner authorizes this app through TikTok's Login Kit, it is granted read-only access to:

  • Basic profile information — display name, avatar, open ID
  • Profile details — bio, profile links, verification status
  • Account statistics — follower count, following count, total likes, video count
  • Public video listings and their engagement metrics — views, likes, comments, shares

How this data is used

Data is fetched live from TikTok's API, on request, to display the account owner's own analytics back to them. It is used for no other purpose — no advertising, no profiling, no analytics beyond what's described here, and no resale or transfer to any third party.

Where this data is stored

This integration runs entirely on the account owner's own machine. The OAuth access and refresh tokens are stored locally in that environment and are never transmitted anywhere other than directly to TikTok's own API. No separate server or database holds a copy of this data.

Revoking access

The account owner can revoke this app's access at any time from TikTok's own account settings (Settings and privacy → Security and permissions → Manage apps). Revoking access immediately invalidates the stored tokens.

Changes to this policy

Because this is a single-user personal tool, this policy will only change if the way the integration itself works changes. The "last updated" date above reflects the most recent such change.
